## Aula 02 - Sintaxe Essencial e Tipos Básicos

Conteúdos praticados nesta aula:
- Variáveis, constantes e convenções da PEP 8
- Tipos primitivos (int, float, str, bool) e conversão de tipos
- Operadores aritméticos, de comparação e lógicos
- Manipulação de texto com métodos de string e f-strings
- Estruturas condicionais (if, elif, else)
- Mini-lab: Calculadora de IMC com validação de dados

## Como Executar

Acesse a pasta da aula e execute o script desejado via terminal:

```bash
cd aula-02-sintaxe-basica
python3 01_variaveis_e_constantes.py
python3 mini_lab_calculadora_imc.py
```
