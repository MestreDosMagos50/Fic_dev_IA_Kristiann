## 📚 Aula 02 — Sintaxe Essencial e Tipos Básicos

Tópicos abordados nesta aula:
- **Variáveis e Constantes**: Nomenclatura PEP 8 (`snake_case`, `SCREAMING_SNAKE_CASE`), tipagem dinâmica e verificação de tipos com `type()`.
- **Tipos de Dados Básicos**: Manipulação de `int`, `float`, `str`, `bool` e conversão de tipos (type casting).
- **Operadores**: Operadores aritméticos, relacionais, lógicos (`and`, `or`, `not`) e de atribuição acumulativa.
- **Strings e f-strings**: Métodos utilitários de string (`.strip()`, `.upper()`, `.replace()`, etc.) e formatação com `f-strings`.
- **Controle de Fluxo**: Estruturas de decisão `if`, `elif`, `else` e expressões condicionais (if ternário).
- **Mini-lab (Calculadora de IMC)**: Aplicação interativa em Python com validação de entrada, cálculo de IMC e classificação segundo a Tabela da OMS.

## 🚀 Como Executar os Scripts

Certifique-se de ter o Python 3 instado em sua máquina.

1. Acesse o diretório da aula:
   ```bash
   cd aula-02-sintaxe-basica
   ```

2. Execute o script desejado:
   ```bash
   python3 01_variaveis_e_constantes.py
   python3 02_tipos_de_dados.py
   python3 03_operadores.py
   python3 04_strings_e_fstrings.py
   python3 05_controle_de_fluxo.py
   python3 mini_lab_calculadora_imc.py
   ```
