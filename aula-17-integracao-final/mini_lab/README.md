# Assistente Python

MVP de um assistente educacional de Python utilizando FastAPI, Streamlit, LangChain e OpenAI API.

## Estrutura
- `backend/`: API em FastAPI
- `frontend/`: Interface em Streamlit
- `chains/`: Lógica do LangChain (QA e RAG)
- `docs/`: Documentos para a base de conhecimento (RAG)
