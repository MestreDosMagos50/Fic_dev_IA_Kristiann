🛡️ Script do Usuário de Governança (Princípio do Menor Privilégio)

Uma ferramenta de governança nunca deve possuir permissão de escrita. Criamos um perfil restrito a USAGE e SELECT:

SQL — 01_usuario_openmetadata.sql 
-- 1. Criação do Usuário
CREATE ROLE openmetadata_user WITH LOGIN PASSWORD 'openmetadata_pass123';

-- 2. Permissão de Conexão
GRANT CONNECT ON DATABASE meu_banco_de_dados TO openmetadata_user;

-- 3. USAGE nos Schemas (Navegação de Metadados)
GRANT USAGE ON SCHEMA staging, silver, gold, public TO openmetadata_user;

-- 4. Somente LEITURA nas tabelas atuais
GRANT SELECT ON ALL TABLES IN SCHEMA staging, silver, gold, public TO openmetadata_user;

-- 5. Privilégios para tabelas futuras
ALTER DEFAULT PRIVILEGES IN SCHEMA staging, silver, gold, public GRANT SELECT ON TABLES TO openmetadata_user;

-- 6. Bloqueio explícito de DDL/DML de escrita
REVOKE CREATE ON SCHEMA staging, silver, gold, public FROM openmetadata_user;
